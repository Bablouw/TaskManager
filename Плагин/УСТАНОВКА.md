# Установка

Для обычной установки запустите двойным щелчком:

```text
Установить.bat
```

BAT-файл запускает PowerShell с разрешением выполнения локального установщика и оставляет окно открытым, чтобы был виден результат.

Также установщик можно запустить вручную из PowerShell:

```powershell
.\Установить.ps1
```

Без параметров установщик найдёт установленные Revit 2021–2024 и разложит соответствующие сборки в локальный профиль пользователя.

Для установки выбранных версий:

```powershell
.\Установить.ps1 -RevitVersion 2021,2024
```

Версии можно передать и BAT-файлу из командной строки: `Установить.bat -RevitVersion 2021,2024`.

Чтобы удалить TaskExchange из установленных папок Revit, сначала закройте соответствующие версии Revit, затем запустите `Удалить.bat`. По умолчанию обрабатываются Revit 2021–2024; отдельную версию можно указать так: `Удалить.bat -RevitVersion 2021`. Исходная папка плагина и пользовательские настройки не удаляются.

Файлы копируются в `%APPDATA%\Autodesk\Revit\Addins\<версия>`. Установщик снимает блокировку Windows с исходных и скопированных файлов. Если нужная версия Revit открыта, обновление будет подготовлено для следующего запуска.

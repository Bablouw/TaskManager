# UNI — Обмен заданиями

Плагин Revit для получения заданий из связанных моделей. Поддерживаются отдельные сборки для Revit 2021, 2022, 2023 и 2024.

## Возможности

- кнопка **Задания** на вкладке **Надстройки**;
- немодальные окна менеджера и списка заданий: модель Revit остаётся доступной для навигации и выделения; окна автоматически закрываются при закрытии своего документа;
- автоматическая проверка и загрузка `UNI_Задание.rfa` из папки плагина;
- выбор одной или нескольких загруженных связей;
- фильтрация заданий по локально выбранному параметру проекта:
  - `Задание для ЭОМ`;
  - `Задание для СС`;
  - `Задание для АК`;
- статусы: новое, получено, изменены координаты, изменены параметры, удалено в источнике, найдено в другой связи;
- добавление и обновление локальных экземпляров в текущем рабочем наборе;
- удаление только локальной копии задания;
- выбор и показ задания в текущей модели;
- для задания с изменёнными координатами кнопка «Показать на виде» показывает средствами Revit два полупрозрачных маркера и вектор от текущего положения к положению в связи; графика остаётся привязанной к плану при масштабировании, а «Добавить в проект / Обновить» переносит локальный экземпляр в эту точку;
- переключатели статусов и поиск по значениям параметров в окне заданий;
- скрытие заданий, переданных из текущей модели и отображаемых в связях;
- сведения о выбранном задании: ID в проекте и связи, пользователь и даты загрузки и обновления;
- сопоставление параметров и правила назначения УГО: параметр переносится стрелкой из списка «Добавление параметров», а типоразмер УГО выбирается из раскрывающегося списка;
- локальные конфигурации, переименование, импорт и экспорт JSON;
- хранение происхождения задания в Revit Extensible Storage;
- журнал операций в `DataStorage` текущего проекта;
- кнопка «Задание у смежников» пока неактивна — логика её отображения ещё не согласована.

Плагин никогда не изменяет документы Revit-связей.

## Сборка

На компьютере должны быть установлены Revit 2021–2024 по стандартным путям Autodesk и .NET SDK.

```powershell
.\Исходник\build.ps1 -Configuration Release
```

Готовые пакеты создаются в `Плагин\Revit2021` … `Плагин\Revit2024`. Каждая версия содержит собственную DLL, `.addin`, установщик и локальную копию семейства формата Revit 2021.
Рядом создаются переносимые архивы `TaskExchange-Revit2021.zip` … `TaskExchange-Revit2024.zip`.

## Установка

Выполните:

```powershell
.\Плагин\Установить.ps1
```

Без параметров устанавливаются пакеты для обнаруженных Revit 2021–2024. Можно указать одну или несколько версий: `.\Плагин\Установить.ps1 -RevitVersion 2021,2024`. Плагин устанавливается в локальный профиль пользователя `%AppData%\Autodesk\Revit\Addins\<версия>`, а блокировка Windows снимается со всех файлов пакета.
Если Revit запущен, установщик помещает обновление в отдельную папку и переключает манифест для следующего запуска. Текущий сеанс продолжит работать со старой DLL до перезапуска Revit.

Для установки из отдельного ZIP распакуйте его в локальную папку и выполните находящийся внутри `install.ps1`.

## Первый запуск

1. Откройте проект и убедитесь, что необходимые связи загружены.
2. Откройте **Надстройки → Обмен заданиями → Задания**.
3. Если семейства `UNI_Задание` нет, плагин загрузит его из собственной локальной папки.
4. В настройках вручную введите точное имя параметра проекта, соответствующего дисциплине пользователя.
5. Создайте конфигурацию сопоставления параметров.
6. Выберите связи и откройте список заданий.

## Технические замечания

- Исходным заданием считается любой экземпляр элемента в связанной модели, у которого выбранный параметр проекта имеет значение «Да». Для точечных элементов используется точка размещения, для линейных — середина кривой, для остальных — центр габаритов. `UNI_Задание` используется как локальное семейство-контейнер в принимающей модели.
- Устойчивый ключ включает `UniqueId` экземпляра связи, идентификатор исходной модели и `UniqueId` исходного элемента.
- Координаты пересчитываются через полную трансформацию экземпляра связи.
- Локальное семейство `UNI_Задание` должно поддерживать размещение по точке без обязательной грани-хоста. Ошибка отдельного элемента не отменяет обработку остальных выбранных заданий.
- Правило УГО может проверять параметр экземпляра или параметр типа исходного элемента. Список УГО берётся из вложенного семейства аннотации, связанного с параметром типа `УГО` в `UNI_Задание`. Если подходящего правила нет, используется УГО `ЭОМ_Эл.вывод`. Типоразмер контейнера получает имя `Семейство источника/Тип источника`, например `UNI_500_Шкаф телекоммуникационный_R21_/СС_ШкафТелекоммуникационный`. Семейство в связи не изменяется.
- Локальные настройки находятся в `%AppData%\UNI\TaskExchange\settings.json`, журналы — в `%LocalAppData%\UNI\TaskExchange\Logs`.
- Сетевые диски плагину не требуются.

## Структура репозитория

- `Исходник` — решение Visual Studio, проект C#, ресурсы и сценарий сборки.
- `Плагин` — готовые версии для Revit 2021–2024, переносимые ZIP‑архивы и общий установщик.
